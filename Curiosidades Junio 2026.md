## 🤖 El threat model "Glasswind" de Anthropic y "Claudemito"

**Clase:** 12.06.2026 (Crocodile, Archetype)

- Carlos explica el proyecto **Glasswind** de Anthropic: el modelo "Claude de mitos" (Claude Mythos)
- El modelo era tan peligroso que **no lo podían sacar al público** porque encontraba vulnerabilidades demasiado rápido
- Crearon el proyecto Glasswind con Google y Amazon para parchear infraestructura
- La gente empezó a llamar al modelo **"Claudemito"** (diminutivo irónico)
- Carlos explica: **"Este modelo que se llama Cloud de mitos es el mejor que ha desarrollado el ser humano, nos va a sustituir y nos va a quitar el trabajo a todos."** (con tono irónico)
- Ahora la nueva familia es **Fable 5**, capada con "guardarrails" que impiden hablar de ciberseguridad
- Los hackers intentan **by-passear los guardarrails** para usarlo para ciber

> 💡 **La ironía:** Anthropic creó un modelo tan bueno para ciber que tuvieron que caparlo para que la gente no lo usara para encontrar zero days

## 📅 Datos técnicos sueltos de junio

| Dato | Contexto |
|---|---|
| **NFS = puerto 2049** | Protocolo para compartir carpetas en red de Linux |
| **Rock You es un diccionario enorme** | Se usa para fuerza bruta de hashes y contraseñas |
| **John the Ripper vs HashCat** | John es más cómodo, HashCat es más rápido con GPU |
| **LFI = Local File Inclusion** | Vulnerabilidad que permite cargar archivos locales del servidor |
| **Reverse Shell requiere RCE** | Necesitas ejecución remota de comandos antes de usar reverse shell |
| **El puerto 80 nunca es vulnerable en sí** | Es el servicio lo que puede tener vulnerabilidades |
| **Cloudflare protege el 80% del tráfico** | Usa lámparas de lava para generar claves aleatorias |
| **WordPress es "una gran mierda"** | Por la cantidad de plugins que usa la gente |
| **Burp Suite Community es gratis** | Pero tiene limitaciones en Intruder |
| **La carpeta /tmp es para subir malware** | Porque tiene permisos de escritura y ejecución |
