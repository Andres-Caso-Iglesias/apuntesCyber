# Glosario de Ciberseguridad

> Referencia consolidada de términos, acrónimos y conceptos usados en auditoría, pentesting y seguridad ofensiva/defensiva.

---

## A

| Término | Definición |
|---------|-----------|
| **API** | Application Programming Interface. Interfaz que expone funciones del backend para que clientes las consuman |
| **AuthN** | Autenticación. Verificación de identidad (quién eres) |
| **AuthZ** | Autorización. Control de permisos (qué puedes hacer) |
| **ACL** | Access Control List. Lista de control de acceso que define permisos sobre recursos |
| **AD** | Active Directory. Servicio de directorio de Microsoft para gestión de usuarios y equipos |
| **APT** | Advanced Persistent Threat. Amenaza persistente avanzada, ataque prolongado y selectivo |
| **AES** | Advanced Encryption Standard. Algoritmo de cifrado simétrico ampliamente utilizado |
| **ARP** | Address Resolution Protocol. Protocolo para resolver direcciones IP a direcciones MAC |
| **Asset** | Activo. Cualquier recurso de valor (datos, hardware, software, servicios) |

---

## B

| Término | Definición |
|---------|-----------|
| **BOLA** | Broken Object Level Authorization. OWASP API1: acceso a objetos ajenos cambiando IDs |
| **Brute Force** | Ataque de fuerza bruta: probar todas las combinaciones posibles de credenciales |
| **Bug Bounty** | Programa donde organizaciones recompensan a investigadores por encontrar vulnerabilidades |
| **Burp Suite** | Suite de herramientas para auditoría y pentesting de aplicaciones web |
| **Bash** | Bourne Again Shell. Intérprete de comandos estándar en Linux |
| **Bypas** | Evadir un mecanismo de seguridad o control |
| **Backdoor** | Puerta trasera: acceso oculto al sistema para evadir autenticación |

---

## C

| Término | Definición |
|---------|-----------|
| **C2** | Command and Control. Servidor que controla malware o implantes remotos |
| **CSP** | Content Security Policy. Política de seguridad que restringe recursos que el navegador puede cargar |
| **CORS** | Cross-Origin Resource Sharing. Mecanismo que permite o restringe peticiones entre orígenes |
| **CSRF** | Cross-Site Request Forgery. Ataque que fuerza acciones en nombre de un usuario autenticado |
| **CVE** | Common Vulnerabilities and Exposures. Identificador estándar de vulnerabilidades conocidas |
| **CWE** | Common Weakness Enumeration. Enumeración de debilidades de seguridad comunes |
| **CVSS** | Common Vulnerability Scoring System. Sistema de puntuación para severidad de vulnerabilidades |
| **CIDR** | Classless Inter-Domain Routing. Método de ruteo que reemplaza el sistema de clases |
| **CNAME** | Canonical Name. Registro DNS que alias un nombre a otro |
| **CGI** | Common Gateway Interface. Protocolo para ejecutar scripts en el servidor web |
| **Cookie** | Pequeño archivo que el servidor envía al navegador para almacenar estado |

---

## D

| Término | Definición |
|---------|-----------|
| **DOM** | Document Object Model. Representación en árbol del documento HTML |
| **DNS** | Domain Name System. Sistema que resuelve nombres de dominio a direcciones IP |
| **DoS** | Denial of Service. Ataque que impide el acceso legítimo a un servicio |
| **DDoS** | Distributed Denial of Service. DoS distribuido desde múltiples fuentes |
| **Data Exfiltration** | Exfiltración de datos: robo o fuga no autorizada de información |
| **Default Credentials** | Credenciales por defecto que vienen con software o dispositivos |
| **Decoy** | Honeypot o señuelo. Sistema que imita uno real para detectar atacantes |
| **Dashboard** | Panel de control. Interfaz con métricas y estado del sistema |

---

## E

| Término | Definición |
|---------|-----------|
| **EoP** | Escalation of Privilegios. Obtener permisos superiores a los asignados |
| **Enumeration** | Enumeración. Recopilación de información sobre usuarios, recursos y servicios |
| **Exfiltration** | Exfiltración. Extracción no autorizada de datos de una red o sistema |
| **Exploit** | Código o técnica que aprovecha una vulnerabilidad para ejecutar código no autorizado |
| **Endpoint** | Punto final de una API o servicio al que se envían peticiones |
| **Evasion** | Técnica para evadir controles de seguridad (WAF, antivirus, IDS) |
| **ELK** | Elasticsearch, Logstash, Kibana. Stack para búsqueda, logs y visualización |
| **Escrow** | Depósito en custodia. En software: código fuente bajo tercero hasta cumplir condiciones |

---

## F

| Término | Definición |
|---------|-----------|
| **Fuzzing** | Técnica que envía datos aleatorios o malformados para encontrar vulnerabilidades |
| **FQDN** | Fully Qualified Domain Name. Nombre de dominio completo y absoluto |
| **Firewall** | Sistema que filtra tráfico de red según reglas de seguridad |
| **Footprinting** | Recopilación inicial de información sobre un objetivo |
| **Foothold** | Punto de acceso establecido en un sistema tras una explotación |
| **Fail2ban** | Herramienta que bloquea IPs que muestran patrones de ataque |

---

## G

| Término | Definición |
|---------|-----------|
| **Graph** | Estructura de nodos y aristas. Usado en ML para representar relaciones |
| **Grafana** | Herramienta de visualización y monitoreo de métricas |
| **GPG** | GNU Privacy Guard. Implementación de PGP para cifrado y firmas |
| **GCP** | Google Cloud Platform. Plataforma en la nube de Google |
| **GitOps** | Modelo de operaciones donde Git es la fuente de verdad para infraestructura |
| **Gherkin** | Lenguaje de especificación para tests de aceptación (Given/When/Then) |

---

## H

| Término | Definición |
|---------|-----------|
| **HSTS** | HTTP Strict Transport Security. Fuerza al navegador a usar HTTPS |
| **Honeypot** | Sistema señuelo para atraer y detectar atacantes |
| **Hashing** | Transformación unidireccional de datos (SHA256, bcrypt, argon2) |
| **Hashcat** | Herramienta para crackear hashes con GPU |
| **Hashcat** | Versión GPU de john the ripper, más rápido |
| **Header** | Cabecera HTTP. Metadatos de petición o respuesta |
| **Hijacking** | Secuestro de sesiones, conexiones o procesos |
| **Hook** | Punto de enganche en código para interceptar o modificar comportamiento |
| **Heuristic** | Análisis basado en reglas o patrones, no en firmas exactas |

---

## I

| Término | Definición |
|---------|-----------|
| **IDOR** | Insecure Direct Object Reference. Acceso a objetos cambiando identificadores (BOLA) |
| **IoC** | Indicator of Compromise. Señal de que un sistema ha sido comprometido |
| **IDS** | Intrusion Detection System. Sistema de detección de intrusiones |
| **IPS** | Intrusion Prevention System. Sistema de prevención de intrusiones |
| **IPSec** | Protocolo de seguridad para comunicaciones IP (VPN) |
| **IV** | Initialization Vector. Valor aleatorio usado en cifrado simétrico |
| **IaC** | Infrastructure as Code. Infraestructura gestionada con código versionado |
| **Ingress** | Punto de entrada a un cluster Kubernetes |
| **Inference** | En ML: proceso de hacer predicciones con un modelo entrenado |

---

## J

| Término | Definición |
|---------|-----------|
| **JWT** | JSON Web Token. Token firmado para autenticación stateless |
| **John the Ripper** | Herramienta para crackear contraseñas por fuerza bruta |
| **JSON** | JavaScript Object Notation. Formato de intercambio de datos |
| **Jenkins** | Servidor de integración continua (CI/CD) |
| **Jinja2** | Motor de plantillas en Python, vulnerable a SSTI |

---

## K

| Término | Definición |
|---------|-----------|
| **Kerberos** | Protocolo de autenticación basado en tickets |
| **Kibana** | Herramienta de visualización del stack ELK |
| **Kubernetes (K8s)** | Orquestador de contenedores |
| **Keylogger** | Software que registra pulsaciones de teclado |
| **Kill Chain** | Modelo que describe las fases de un ciberataque |
| **Known-Plaintext Attack** | Ataque donde se conoce parte del texto cifrado |

---

## L

| Término | Definición |
|---------|-----------|
| **Log** | Registro de eventos del sistema o aplicación |
| **LOLBins** | Living Off the Land Binaries. Uso de herramientas legítimas del SO para atacar |
| **Local File Inclusion (LFI)** | Inclusión de archivos locales del servidor |
| **LDAP** | Lightweight Directory Access Protocol. Protocolo para directorios |
| **LLM** | Large Language Model. Modelo de lenguaje grande (GPT, Claude, etc.) |
| **Listener** | Servidor que escucha conexiones entrantes (netcat, Burp) |

---

## M

| Término | Definición |
|---------|-----------|
| **MITM** | Man-in-the-Middle. Interceptación de comunicaciones entre dos partes |
| **Malware** | Software malicioso (virus, troyano, ransomware, spyware) |
| **Metasploit** | Framework de desarrollo y ejecución de exploits |
| **MFA** | Multi-Factor Authentication. Autenticación con múltiples factores |
| **Mass Assignment** | Asignación masiva: el backend acepta campos extras del cliente |
| **Microservice** | Arquitectura de servicios pequeños e independientes |
| **MITRE ATT&CK** | Marco de tácticas y técnicas de ataque cibernético |
| **ML** | Machine Learning. Aprendizaje automático |
| **ModSecurity** | WAF open source para Apache/Nginx/IIS |

---

## N

| Término | Definición |
|---------|-----------|
| **NAT** | Network Address Translation. Traducción de direcciones de red |
| **Nmap** | Herramienta de escaneo y descubrimiento de red |
| **Netcat (nc)** | Herramienta de lectura/escritura de conexiones de red |
| **NFS** | Network File System. Sistema de archivos en red |
| **Nginx** | Servidor web y proxy inverso de alto rendimiento |
| **Nonce** | Número usado una sola vez. Previene repetición de peticiones |
| **NTLM** | Protocolo de autenticación de Microsoft basado en hash |

---

## O

| Término | Definición |
|---------|-----------|
| **OWASP** | Open Worldwide Application Security Project. Proyecto de seguridad de aplicaciones |
| **OSINT** | Open Source Intelligence. Recopilación de información de fuentes abiertas |
| **OAuth** | Protocolo de autorización para acceso delegado |
| **OOB** | Out-of-Band. Comunicación por canal auxiliar (para ciegos) |
| **Obfuscation** | Técnica para hacer código difícil de leer/analizar |
| **Origin Server** | Servidor de origen al que llega la petición original |

---

## P

| Término | Definición |
|---------|-----------|
| **Pentest** | Penetration Test. Prueba de penetración autorizada |
| **Payload** | Código que se ejecuta tras explotar una vulnerabilidad |
| **Post-Exploitation** | Acciones realizadas tras obtener acceso inicial |
| **Privilege Escalation** | Escalada de privilegios: obtener permisos superiores |
| **Proxy** | Intermediario que reenvía peticiones |
| **Proxychains** | Herramienta que fuerza tráfico a pasar por proxies SOCKS/HTTP |
| **Phishing** | Ingeniería social para robar credenciales |
| **PHPSESSID** | Cookie de sesión de PHP |

---

## Q

| Término | Definición |
|---------|-----------|
| **Query String** | Parámetros de una URL después del `?` |
| **QR Code** | Código bidimensional con información |
| **Quarantine** | Aislamiento de un sistema o archivo infectado |

---

## R

| Término | Definición |
|---------|-----------|
| **RCE** | Remote Code Execution. Ejecución remota de código |
| **Reverse Shell** | Conexión entrante desde la víctima al atacante |
| **Rootkit** | Software que oculta presencia en el sistema |
| **Ransomware** | Malware que cifra datos y pide rescate |
| **Role** | Rol. Nivel de permisos en RBAC |
| **RBAC** | Role-Based Access Control. Control de acceso basado en roles |
| **Regex** | Expresión regular. Patrón para búsqueda/manipulación de texto |
| **RDP** | Remote Desktop Protocol. Protocolo de escritorio remoto de Microsoft |
| **Recon** | Reconocimiento. Fase inicial de un pentest |

---

## S

| Término | Definición |
|---------|-----------|
| **SAST** | Static Application Security Testing. Análisis estático de código |
| **DAST** | Dynamic Application Security Testing. Análisis dinámico (runtime) |
| **SQLi** | SQL Injection. Inyección de código SQL |
| **SSTI** | Server-Side Template Injection. Inyección en plantillas del servidor |
| **SSRF** | Server-Side Request Forgery. El servidor hace peticiones a destinos elegidos por el atacante |
| **Session Hijacking** | Secuestro de sesiones |
| **Shadow Copy** | Copia instantánea de volumen (Windows) |
| **Sandbox** | Entorno aislado para ejecutar código sospechoso |
| **Subdomain** | Subdominio. Parte del dominio principal |
| **Subnet** | Subred. División de una red IP |

---

## T

| Término | Definición |
|---------|-----------|
| **Token** | Credencial digital que representa identidad o permisos |
| **TTP** | Tactics, Techniques, and Procedures. Tácticas, técnicas y procedimientos |
| **Traffic Analysis** | Análisis de tráfico de red |
| **TCP** | Transmission Control Protocol. Protocolo de transporte fiable |
| **TLS** | Transport Layer Security. Protocolo de cifrado en transporte |
| **Tabnabbing** | Ataque que cambia el contenido de una pestaña inactiva |
| **Threat Model** | Modelo de amenazas. Identificación y evaluación de riesgos |

---

## U

| Término | Definición |
|---------|-----------|
| **URL** | Uniform Resource Locator. Dirección de un recurso web |
| **URL Encoding** | Codificación de caracteres especiales en una URL |
| **UDP** | User Datagram Protocol. Protocolo de transporte sin conexión |
| **Upstream Server** | Servidor al que se reenvía la petición (proxy → upstream) |

---

## V

| Término | Definición |
|---------|-----------|
| **VPC** | Virtual Private Cloud. Red privada en la nube |
| **VM** | Virtual Machine. Máquina virtual |
| **VPN** | Virtual Private Network. Red privada virtual |
| **Vulnerability** | Debilidad que puede ser explotada para comprometer un sistema |
| **VM Escape** | Escapar de una máquina virtual al host |
| **VirtualBox** | Software de virtualización de Oracle |
| **Virus** | Malware que se replica adjuntándose a otros archivos |
| **Vault** | Almacén de secretos (HashiCorp Vault) |

---

## W

| Término | Definición |
|---------|-----------|
| **WAF** | Web Application Firewall. Firewall para aplicaciones web |
| **Webshell** | Script malicioso subido a un servidor web |
| **WPSec** | WordPress Security. Auditoría de WordPress |
| **WiFi Pineapple** | Dispositivo de auditoría WiFi |

---

## X

| Término | Definición |
|---------|-----------|
| **XSS** | Cross-Site Scripting. Inyección de scripts en el navegador |
| **XXE** | XML External Entity. Entidades externas en XML para SSRF/lectura de archivos |
| **XML** | Extensible Markup Language. Formato de datos estructurado |
| **XSS** | Inyección de código en el navegador del usuario |

---

## Y

| Término | Definición |
|---------|-----------|
| **YAML** | YAML Ain't Markup Language. Formato de configuración legible por humanos |

---

## Z

| Término | Definición |
|---------|-----------|
| **Zero-Day** | Vulnerabilidad desconocida para el vendor, sin parche disponible |
| **Zero Trust** | Modelo de seguridad que no confía en ningún usuario o dispositivo por defecto |
| **Zombie** | Máquina comprometida controlada por un atacante (botnet) |
