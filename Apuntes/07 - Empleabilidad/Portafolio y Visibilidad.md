## ① Portafolio esencial

| Elemento | Qué incluye |
|---------|-----------|
| **Blog técnico** | Artículos claros y concisos sobre tus experiencias y conocimientos |
| **GitHub** | Scripts, herramientas, proyectos personales |
| **Plataformas CTF** | Perfil activo en HTB, THM, VulnHub (máquinas resueltas) |
| **YouTube (opcional)** | Vídeos explicando técnicas o walkthroughs |
| **LinkedIn** | Perfil optimizado con palabras clave de ciberseguridad |

> [!warning] REGLA DE ORO
> No esperes a ser experto para publicar. **Empieza ahora.** Escribir y compartir te obliga a entender mejor.

## ①bis GitHub como portafolio

Un buen perfil de GitHub para ciberseguridad incluye:

1. **README.md del perfil** (repo especial `usuario/usuario`): preséntate, especialidades, contactos
2. **Writeups de CTF**: `CTF-NombreEvento-2024/` con `README.md` (solución), `exploit.py`, `screenshots/`
3. **Herramientas propias**: scanner básico, automatizaciones — con README claro (qué hace, cómo se usa)
4. **Laboratorios documentados**: HTB/THM writeups, documentación de tu home lab
5. **Commits regulares**: la gráfica de actividad es visible; demuestra constancia

> [!important] ESTRUCTURA
> Los reclutadores **no leen el código. Leen el README.** Cada repositorio debe tener un README claro: qué es, para qué sirve, cómo se usa, captura de pantalla.

## ①ter LinkedIn: optimización del perfil

| Sección | Recomendación |
|---------|--------------|
| Foto profesional | No obligatoria pero aumenta visibilidad. Fondo neutro |
| Titular (headline) | Describe qué haces y en qué te especializas, no solo el título |
| About/Acerca de | 3-5 líneas: quién eres, qué haces, qué buscas |
| Experiencia | Logros, no solo responsabilidades. Métricas si es posible |
| Certificaciones | Añade todas: eJPT, Security+, OSCP... |
| Habilidades | Mínimo 50. Las primeras 3 son las más importantes |
| Publicaciones | Un post técnico al mes genera mucha visibilidad |

```
❌ Malo:
"Estudiante de ciberseguridad"
"Buscando trabajo en IT"

✅ Bueno:
"Pentester en formación | eJPT | CTF player | HackTheBox Top 10%"
"Ciberseguridad ofensiva | Bug Bounty | Python | Kali Linux"
"SOC Analyst | Blue Team | SIEM | Threat Detection"
```

## ② Presencia pública

```
Blog + GitHub + HTB + LinkedIn + Conferencias + Open Source
 = DEMOSTRACIÓN visible de habilidades
 = Las empresas te encuentran
 = Ventaja competitiva sobre otros candidatos
```

> [!tip] POR QUÉ IMPORTA
> Las empresas buscan perfiles públicos. Si solo tienes un CV y nada más, eres "otro más". Con presencia pública, eres **candidato identificable**.

## ③ Qué compartir

| Qué | Dónde |
|-----|-------|
| Artículos escritos (blog personal) | Blog, LinkedIn |
| Scripts útiles | GitHub |
| Walkthroughs de máquinas CTF | Blog, HTB |
| Experiencias y aprendizajes | LinkedIn |
| Análisis de vulnerabilidades | Blog |
| Participación en comunidades | Discord, foros |

### Canales de personal branding

| Canal | Descripción |
|-------|------------|
| Blog técnico | Medium, Substack, GitHub Pages. Un post al mes sobre algo que hayas aprendido |
| Twitter/X | Seguir investigadores, compartir writeups, comentar CVEs nuevas |
| YouTube / Twitch | Streamings de CTF o tutoriales. Alta visibilidad, alto esfuerzo |
| Conferencias | DEF CON, Black Hat, RootedCON, NavajaNegra. Asistir y hacer networking |
| Comunidades Discord | HTB, THM, servers del sector. Networking |
| Bug Bounty | HackerOne, Bugcrowd. CVEs propios = muchísimo valor en el CV |

> [!tip] CONSEJO CLAVE
> No tienes que hacer todo a la vez. Elige **1-2 canales** y sé consistente. Un blog con 10 artículos técnicos de calidad vale más que 50 posts de relleno.

## ④ Por qué es importante

```
Portafolio + presencia pública
 → Las empresas te encuentran (no tienes que ir a buscarlas)
 → Ventaja competitiva sobre otros candidatos
 → Demuestra capacidad de comunicación
 → Muestra compromiso con la comunidad
```

> [!important] MENTALIDAD
> **No es por vanidad, es por supervivencia.** En un mercado saturado, el que no se ve, no existe.
