## ① Portafolio esencial

| Elemento | Qué incluye |
|---------|-----------|
| **Blog técnico** | Artículos claros y concisos sobre tus experiencias y conocimientos |
| **GitHub** | Scripts, herramientas, proyectos personales |
| **Plataformas CTF** | Perfil activo en HTB, THM, VulnHub (máquinas resueltas) |
| **YouTube (opcional)** | Vídeos explicando técnicas o walkthroughs |
| **LinkedIn** | Perfil optimizado con palabras clave de ciberseguridad |

> [!warning] REGLA DE ORO
> No esperes a ser experto para publicar. **Empieza ahora.** Escribir y compartir te obliga a entender mejor.

---

## ② Presencia pública

```
Blog + GitHub + HTB + LinkedIn + Conferencias + Open Source
 = DEMOSTRACIÓN visible de habilidades
 = Las empresas te encuentran
 = Ventaja competitiva sobre otros candidatos
```

> [!tip] POR QUÉ IMPORTA
> Las empresas buscan perfiles públicos. Si solo tienes un CV y nada más, eres "otro más". Con presencia pública, eres **candidato identificable**.

---

## ③ Qué compartir

| Qué | Dónde |
|-----|-------|
| Artículos escritos (blog personal) | Blog, LinkedIn |
| Scripts útiles | GitHub |
| Walkthroughs de máquinas CTF | Blog, HTB |
| Experiencias y aprendizajes | LinkedIn |
| Análisis de vulnerabilidades | Blog |
| Participación en comunidades | Discord, foros |

---

## ④ Por qué es importante

```
Portafolio + presencia pública
 → Las empresas te encuentran (no tienes que ir a buscarlas)
 → Ventaja competitiva sobre otros candidatos
 → Demuestra capacidad de comunicación
 → Muestra compromiso con la comunidad
```

> [!important] MENTALIDAD
> **No es por vanidad, es por supervivencia.** En un mercado saturado, el que no se ve, no existe.
