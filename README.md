# Apuntes de Ciberseguridad

Repositorio con los apuntes del curso de ciberseguridad. Aquí tiene cada uno sus notas, los informes de los casos prácticos y los comandos que vamos usando.

## Qué hay aquí

- **Apuntes Andres/** — Los apuntes de Andres, organizados por temas
- **Apuntes Chema/** — Los apuntes de Chema, con máquinas de HackTheBox y más
- **Apuntes evolve/** — Bloques del curso evolve
- **apuntes html/** — Clases en formato HTML (no se ve en odsidian)
- **Apuntes/** — Temas extra: certificaciones, normativa, forense, etc.
- **comandos/** — Referencia rápida de herramientas (Nmap, Burp, SQLMap, Hydra...)
- **informes/** — Informes de los casos prácticos (Rockstars, Nike, Banco...)
- **write-ups/** — Resolución de máquinas y retos
- **transcripciones/** — Transcripciones de las clases

## Para qué sirve

Principalmente para tener todo junto y poder buscar cosas rápido. Si estás en el curso te va a venir bien como referencia, y si ya lo terminaste pues para repasar.

## Cómo usarlo

Clona el repo y abre los markdown con lo que quieras (Obsidian, VS Code, el navegador...).

```bash
git clone https://github.com/Andres-Caso-Iglesias/apuntesCyber.git
```

Si usas Obsidian abre directamente la carpeta como vault y te funciona todo con los enlaces internos.

## Colaborar

Si quieres añadir algo o corregir algo mándalo directamente o abre un pull request. Todo lo que se mejore bienvenido es.
