**Repaso de la semana — LFI, XXE y su relación**

Antes de arrancar la máquina se consolidó el mapa conceptual de la semana. La pregunta de arranque fue correcta: ¿qué vulnerabilidad habilita el LFI y el RFI? La respuesta no es el propio LFI sino una variable de aplicación que acepta entrada de usuario sin sanitizar y la usa para abrir un fichero del sistema. Esa variable puede explotarse de formas distintas: via path traversal (punto punto barra encadenado), o via XXE (entidad XML con SYSTEM file://). El Local File Inclusion es siempre la consecuencia, no el vector en sí.

La distinción que se fijó: con path traversal navegas hacia atrás en el árbol de directorios. Con XXE, lees por ruta absoluta desde dentro del servidor, sin necesidad de navegar. Son dos caminos distintos al mismo destino. Y en muchas configuraciones, el XXE no permite path traversal (el punto punto barra rompe el parser XML), por lo que la ruta absoluta es la única vía.

- **La idea clave:** el path traversal y el XXE no son lo mismo. Son dos vectores diferentes que pueden producir el mismo resultado (LFI). Saber cuándo usar cada uno es criterio de auditor, no de script kiddie
