## ① Reconocimiento — Passive vs Active

### Passive (sin tocar el objetivo)

| Herramienta/Opción | Qué hace |
|---|---|
| `whois` | Registro del dominio |
| `nslookup` / `dig` | Resolución DNS, registros MX/TXT |
| `Shodan` / `Censys` / `FOFA` / `ZoomEye` | Búsqueda de IPs, servicios, CVEs |
| `Google Dorking` | Búsqueda avanzada de información expuesta |
| `Wayback Machine` | Páginas históricas |
| `Netlas` | Attack Surface Management |
| `hunter.io` | Emails asociados a un dominio |

### Active (tocando el objetivo)

| Herramienta | Qué hace |
|---|---|
| `Nmap` | Escaneo de puertos, servicios, versiones |
| `Nmap + scripts` | Enumeración avanzada (vuln, auth, brute-force) |
| `httpx` | HTTP probing (saber si un host tiene web) |
| `Gobuster` / `Feroxbuster` / `Ffuf` | Directory fuzzing |
| `Nuclei` | Escaneo de vulnerabilidades con templates |

> [!important] Fase 0: Identificar si es Linux o Windows
> Antes de hacer nada, hay que saber qué sistema operativo tiene la máquina.
>
> **Linux:** TTL ~64
> **Windows:** TTL ~128
>
> Con esto ya sabés qué binarios de privesc buscar (SUID en Linux, potato en Windows).

## ② Interfaz de máquina HTB

Carlos explicó las partes de la interfaz:

| Elemento | Qué es |
|---|---|
| **Destination IP** | IP de la máquina a atacar (se usa en `nmap -sC -sV -p- --open <IP>`) |
| **User.txt** | Flag de usuario (se encuentra en `/home/<usuario>/user.txt`) |
| **Root.txt** | Flag de root (se encuentra en `/root/root.txt`) |

> [!important] El user.txt no siempre está en `/home/`
> A veces el usuario tiene otro home directory o la flag está en otro sitio. Hay que explorar.

## ③ Proceso de resolución de máquinas

### Fases

| # | Fase | Qué se hace |
|---|---|---|
| 1 | **Reconocimiento** | Passive → Active (nmap) |
| 2 | **Enumeración web** | Gobuster/Feroxbuster, revisar archivos encontrados |
| 3 | **Explotación** | Buscar vulnerabilidades, explotar, obtener shell |
| 4 | **Escalada de privilegios** | Buscar SUID, cron jobs, kernel exploits, etc. |
| 5 | **Root** | Obtener la flag de root |

## ④ Reconocimiento — Preguntas a los alumnos

### ¿Qué es un CDN?

> [!important] Respuesta correcta
> Un CDN **solo sirve archivos estáticos**. No redirige todo el tráfico. Si veo el HTML de la página, **no estoy viendo el CDN**.

### ¿Qué son los registros DNS?

- **A** → Dirección IPv4 del dominio
- **AAAA** → Dirección IPv6
- **CNAME** → Alias de otro dominio
- **MX** → Servidor de correo
- **TXT** → Información textual (SPF, DKIM)
- **NS** → Nameserver

### ¿Qué es el WHOIS?

Información de registro del dominio: propietario, fechas, nameservers.

### Herramientas passive

- whois
- nslookup / dig
- Shodan
- FOFA
- Google Dorking
- Wayback Machine

### Herramientas activas

- **Nmap**: escaneo de puertos y servicios
- **httpx**: verificar hosts con servicios web
- **Gobuster**: enumerate directorios

## ⑤ Enumeración web — Construcción de wordlist

```bash
# Construir wordlist con Gobuster
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
```

```bash
# Copiar archivo hash de Windows para crackear con Hashcat
sudo hashcat -m 1000 hash.txt /usr/share/wordlists/rockyou.txt
```

> [!important] Tip sobre wordlists
> Si Gobuster no encuentra nada, intentá con otra wordlist o construí una personalizada con cewl.

## ⑩ Notas de clase

- **Azure no es un dominio como tal**, es un proveedor de servicios cloud. No se puede hacer whois de "Microsoft" o "Azure" de la misma forma que con un dominio propio.
- **DIOS es una wordlist**, no una herramienta de fuzzing. Se usa con dirb, gobuster, etc.
- **Bandit es un juego de(level 0 a level 33)**. Nivel 24: ejecutar un script con un argumento específico.
- **No existe flag en Machines Tier 0**, solo en Starting Point Tier 0 y Tier 1.
- **Hack The Box no tiene interacción** con las máquinas (eslabón de cadena).
