## ① Por qué ha explotado la IA ahora

La IA existía hace doce años como concepto académico, pero era un **árbol de decisión glorificado**: si el input contiene "dolor", haz esto; si además contiene "rodilla", haz esto otro.

### El salto real: GPT 3.5

| Concepto | Árbol de decisión | Red neuronal |
|---|---|---|
| **Mecanismo** | Busca la rama correcta | Genera una respuesta nueva |
| **Tipo** | Categorización | Razonamiento |
| **Ejemplo** | "Si dice 'dolor' → sugerir ibuprofeno" | "Describe síntomas → genera diagnóstico diferencial" |

> [!important] La idea clave
> La IA ha entrado en un **ciclo de retroalimentación** donde cada generación de modelos acelera la creación de los datos que entrenará a la siguiente. Por eso la evolución es exponencial y no lineal.

### El ciclo virtuoso

```
GPT 3.5 → Genera datasets → Entrena GPT 4
GPT 4 → Genera mejores datasets → Entrena GPT 5
GPT 5 → ...
```

## ② Cómo aprende una red neuronal

### Pesos y capas

Cada posición posible del tablero (ej: Tetris) con una pieza concreta es un escenario. Para cada escenario, distintas personas asignan una puntuación del 1 al 10 a cada posible movimiento. La red neuronal registra esas puntuaciones como **pesos ponderados**.

| Capa | Ejemplo (coches) | Peso |
|---|---|---|
| 1ª capa | Marca | Alto |
| 2ª capa | Modelo | Alto |
| 3ª capa | Motor | Medio |
| 4ª capa | Color | Bajo |

### Autoaprendizaje

El autoaprendizaje ocurre cuando la red genera **conexiones nuevas que nadie le programó**. Cuando detecta un patrón que los humanos no habían observado, crea un nodo nuevo. **Nadie sabe exactamente qué pasa dentro** del modelo durante ese proceso, ni siquiera los creadores.

> [!important] La metáfora
> Un árbol de decisión es un **mapa de carreteras**: si vas de A a B, coges esta autopista. Una red neuronal es un **conductor con experiencia**: puede llegar de A a B por una ruta que nunca nadie trazó.

## ③ Datasets — La materia prima

El dataset es el factor **más importante** de cualquier entrenamiento, por encima del hardware y del algoritmo.

### Tres requisitos para un dataset útil

1. **Etiquetado**: cada dato tiene una marca que dice qué es o cuánto vale
2. **Ejemplos negativos**: si entrenas un detector de toros, necesitas toros, pero también vacas, cabras y delfines etiquetados como no-toros
3. **10% para validación**: ese porcentaje nunca se usa en el entrenamiento, se usa después para medir la precisión

### Casos de fracaso por dataset corrupto

| Caso | Problema |
|---|---|
| **Husky vs Lobo** | La red detectaba nieve (90% de fotos de lobos tenían nieve) |
| **GPT 4** | Se retroalimentó del uso de usuarios sin control de calidad |

> [!important] La idea clave
> Meter datos de producción sin curación en un modelo es uno de los **ataques más efectivos** que existen. Se llama **envenenamiento de dataset** y puede corromper un modelo completo.

## ④ Pokémon Go — Dataset a escala planetaria

Pokémon Go no fue un juego. Fue una operación de recolección de dataset para construir un sistema de **navegación por reconocimiento de imágenes** para drones autónomos.

Millones de personas caminaron por sus ciudades con el móvil en alto cazando Pokémons → se mapeó el mundo entero frame a frame → sistema de navegación sin GPS.

> [!important] La idea clave
> El verdadero oro de este siglo son los datos. La diferencia entre un modelo mediocre y uno excelente no está en el algoritmo sino en la **calidad y cantidad del dataset**.

## ⑤ Base de datos vs Grafo relacional vs Red neuronal

| Tipo | Qué es | Utilidad |
|---|---|---|
| **Base de datos SQL** | Tabla con filas y columnas | Filtrar, ordenar |
| **Grafo de Obsidian** | Nodos conectados por hipervínculos | Repositorio de conocimiento |
| **Grafo vectorial (Neo4J)** | Nodos con pesos ponderados | Jerarquía entre datos |
| **Red neuronal con ML** | Autoaprendizaje real | Detectar patrones nuevos |

> [!important] La metáfora
> - **Obsidian** = estantería de tu casa: sabes dónde está cada libro pero los libros no hablan entre sí
> - **Neo4J** = Internet: las páginas están relacionadas y puedes saltar de una a otra
> - **Red neuronal con ML** = un cerebro que ha leído todo Internet y puede generar conocimiento nuevo

## ⑥ Obsidian vs Neo4J — Diferencia práctica

### Obsidian (grafo plano)

```markdown
# Jaguar XE
- Marca: Jaguar
- Color: Rojo
- Año: 2016

## Relaciones
- [[Jaguar]] (marca)
- [[Rojo]] (color)
```

- No tiene pesos ponderados
- No tiene ontología
- No puede hacer A/B testing
- Es un **índice**, no una red neuronal

### Neo4J (grafo vectorial)

```cypher
(jaguar:Coche {nombre: "Jaguar XE"})
  -[:Tiene_Color {peso: 0.3}]-> (rojo:Color)
  -[:Es_Marca {peso: 0.9}]-> (jaguar_marca:Marca)
  -[:Fabricado_en {peso: 0.7}]-> (uk:Pais)
```

- Tiene pesos ponderados
- Tiene ontología (relaciones semánticas)
- Puede hacer A/B testing
- Es una **base de inferencia**

> [!important] La progresión
> Obsidian → Neo4J → Red neuronal con ML
> Cada paso añade una capa de complejidad y capacidad.

## ⑧ Demostración en vivo — Dataset de coches

Carlos ejecutó en directo la transformación de un dataset de cien mil coches (SQLite, 15MB) a nodos de Obsidian usando Claude Code.

### Proceso

1. Claude lee el SQL línea por línea
2. Genera un fichero Markdown por cada coche
3. Los nodos aparecen en Obsidian con hipervínculos
4. El Graph View muestra clusters automáticos (Toyota con Toyota, Jaguar con Jaguar)

> [!important] Lo que quedó visible
> Parece una red neuronal, pero no lo son: son hipervínculos **sin peso semántico**. La diferencia entre eso y Neo4J es la diferencia entre **parecer inteligente y serlo**.

## ⑨ Machine Learning — Cuándo SÍ y cuándo NO

| Situación | ¿Es ML? | Por qué |
|---|---|---|
| Buscar información en internet | **No** | Es deep research, no aprendizaje |
| Mapear información en nodos | **No** | Es indexación |
| Detectar patrones en mamografías | **Sí** | Aprende a detectar algo que no se le enseñó |
| Hacer un bot de Tetris que mejore | **Sí** | Al principio no sabe, luego aprende |
| Crear skills para un agente | **No** | Es documentación, no aprendizaje |

> [!important] La regla
> ML es cuando consigues que el algoritmo **aprenda a hacer algo que al principio no sabía**. Si ya lo sabes hacer y solo estás documentando, no es ML.
