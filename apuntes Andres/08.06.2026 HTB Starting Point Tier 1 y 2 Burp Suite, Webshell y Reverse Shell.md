## Burp Suite — Configuración y Extensiones

### Instalación
- Burp Suite Community ya viene preinstalado en Kali Linux
- Para usarlo con las máquinas HTB hay que configurar el proxy en el navegador

### Extensión imprescindible: Foxy Proxy
- Permite cambiar rápidamente entre proxies en el navegador
- Se configura apuntando a `127.0.0.1:8080` (puerto por defecto de Burp)
- Así todo el tráfico del navegador pasa por Burp Suite para interceptarlo

### Extensión recomendada: Wappalyzer
- Detecta tecnologías de una web sin hacer peticiones
- Muestra: servidor web, frameworks, CMS, CDN, librerías JavaScript
- Es passive — no genera tráfico sospechoso, solo analiza lo que el navegador ya carga
- Funciona tanto en Chrome como en Firefox

### Burp Suite Community vs Pro
- **Community**: funcional para el curso, tiene Repeater e Intruder limitados
- **Pro**: automátaciones más rápidas, escaneos, nécessaire para auditorías reales

## WPScan — Auditoría de WordPress

### Qué es
Herramienta específica para escanear sitios WordPress. Detecta:
- Usuarios enumerados
- Plugins y temas vulnerables
- Configuración insegura

### Uso básico
```bash
wpscan --url http://<IP> --enumerate u   # Enumerar usuarios
wpscan --url http://<IP>                  # Escaneo general
```

### API Key (opcional pero recomendable)
- Registrarse en wpscan.com para obtener una API gratuita
- Con la API se obtiene información más detallada de vulnerabilidades
- Se configura en el archivo de configuración de WPScan
