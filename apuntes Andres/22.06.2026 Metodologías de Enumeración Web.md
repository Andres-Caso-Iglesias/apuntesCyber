## ① Qué es la enumeración web

La enumeración web es una de las fases del **reconocimiento** en una auditoría. Consiste en:

1. **Enviar peticiones** a la web
2. **Observar resultados** (cabeceras, códigos de estado, cookies)
3. **Comparar resultados** entre herramientas
4. **Documentar todo** lo que se encuentre
5. **Formular hipótesis** de vulnerabilidades
6. **Evaluar datos** (sin reventar nada)

> [!important] No es explotación
> La enumeración web **no es explotar**. Es documentar qué hay y qué podría ser vulnerable. La explotación viene después.

---

## ② Qué necesitas saber de una URL

Antes de probar vulnerabilidades, necesitas responder:

| Pregunta | Qué buscar |
|---|---|
| ¿Qué servicios responden? | Cabeceras del servidor |
| ¿Qué rutas existen? | Directorios, archivos ocultos |
| ¿Qué redirecciones hay? | 301, 302, etc. |
| ¿Cómo se autentifica? | Cookies, tokens, OAuth |
| ¿Qué tecnologías usa? | Apache, WordPress, PHP |
| ¿Qué métodos HTTP acepta? | GET, POST, PUT, DELETE |
| ¿Qué parámetros/formularios hay? | Inputs, APIs |

---

## ③ Códigos de estado HTTP

| Código | Significado | Qué indica |
|---|---|---|
| 200 | OK | Funciona correctamente |
| 301 | Moved Permanently | Redirección permanente |
| 302 | Found | Redirección temporal |
| 403 | Forbidden | No tienes acceso |
| 404 | Not Found | No existe |
| 500 | Internal Server Error | Error del servidor |

> [!important] 403 ≠ 404
> Un 403 significa que el recurso **existe** pero no tienes acceso. Un 404 significa que **no existe**. Si ves un 403, vale la pena intentar bypass.

## ④ Cabeceras importantes

| Cabecera | Qué revela |
|---|---|
| `Server` | Tecnología y versión del servidor |
| `X-Powered-By` | Framework o lenguaje usado |
| `Set-Cookie` | Tipo de cookies y flags de seguridad |
| `Location` | A dónde redirige |

## ⑤ Uso de Burp Suite para enumeración

### Configuración

1. Abrir Burp Suite
2. Ir a **Proxy** → **Intercept** → **Intercept is on**
3. Abrir navegador con proxy configurado
4. Navegar por la web → Burp captura las peticiones

### Qué buscar en las peticiones

- **Cookies**: ¿Qué información llevan? ¿Son predecibles?
- **Parámetros**: ¿Qué datos envía el formulario?
- **Cabeceras**: ¿Qué revela el servidor?
- **Rutas**: ¿Qué directorios ocultos hay?

### HTTP History

Todas las peticiones quedan registradas en **HTTP History**. Puedes revisarlas después para buscar información interesante.

## ⑥ Herramientas de enumeración web

| Herramienta | Función |
|---|---|
| **Burp Suite** | Interceptar y modificar tráfico |
| **curl** | Peticiones HTTP desde terminal |
| **WhatWeb** | Detectar tecnologías |
| **Gobuster** | Fuzzing de directorios |
| **FeroxBuster** | Fuzzing de directorios (más rápido) |
| **Nikto** | Escáner de vulnerabilidades |

### curl básico

```bash
curl -I http://IP  # Solo cabeceras
curl -v http://IP  # Información completa
```

### WhatWeb

```bash
whatweb http://IP
```

```
Enviar peticiones → Observar resultados → Comparar → Documentar → Formular hipótesis → Evaluar
```

> [!important] Documentar TODO

## ⑧ WAF (Web Application Firewall)

### Qué es

Un WAF es un firewall específico para web que protege contra inyecciones SQL, XSS, y otros ataques web.

### Capas de protección

```
Internet → Firewall perimetral → WAF → Servidor web
```

### Bypass de WAF

- Buscar vulnerabilidades específicas del fabricante (Imperva, F5, etc.)
- Usar diccionarios de inyecciones
- Técnicas de ofuscación

> [!important] WAF bien configurado = difícil de bypassar
> Un WAF con políticas actualizadas bloquea la mayoría de ataques conocidos. El bypass requiere encontrar vulnerabilidades específicas.

## ⑨ PortSwinger (Web Security Academy)

### Qué es

PortSwinger es una plataforma gratuita con **laboratorios web** para practicar seguridad. Es como Hack the Box pero solo para web.

### Cómo usarlo

1. Crear cuenta gratuita en `portswigger.net`
2. Ir a **Academy** → **Labs**
3. Elegir un laboratorio
4. Se levanta una web temporal para practicar

### Laboratorios recomendados para enumeración

| Laboratorio | Concepto |
|---|---|
| Web Cache Detection | Detección de caché |
| HTTP Request Smuggling | Cabeceras HTTP |
| Authentication | Autenticación |

## ⑩ Notas de clase

- **Enumeración ≠ Explotación**: Es la fase de reconocimiento, no de ataque.
- **Documentar TODO**: Cada hallazgo debe quedar registrado.
- **Comparar herramientas**: Usar al menos dos para contrastar resultados.
- **Códigos de estado**: 403 = existe pero no acceso; 404 = no existe.
- **WAF**: Protege la web. Bypass = vulnerabilidad específica del fabricante.
- **PortSwinger**: Plataforma gratuita para practicar enumeración web.
- **Burp Suite**: Herramienta principal para interceptar y analizar tráfico web.
